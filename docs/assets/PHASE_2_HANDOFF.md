# Phase 2 — Consolidated Asset, Content, Config and Decision Handoff

**Recorded:** 2026-09-19 · **Scope:** M08–M14 (Church → Vinyl Café → VARcade → Cottage/Marcelino → Sunberry Fields → The Everkeep → Living Map).
**Rule applied:** every functional system is finished and works with the Sheet as the source of truth. Where art or personal content is missing, the runtime shows a **clearly labelled temporary visual** ("Temporary visual — artwork pending") or an honest "still being prepared" state. **Nothing here was invented**: no religious text, song, message, narration, achievement copy or personal wording exists in code. The `SAMPLE …` strings you see in the preview live only in an in-memory fixture (`scripts/lib/phase2-fixture.mjs`) and never in the live Sheet.

How the runtime decides content is missing: a value that is blank, a `<PLACEHOLDER>`, disabled, or (for Church) not `review_status = approved` is treated as absent and is never shown.

## 5. Decisions still Open in the Living Bible — what was built, and what needs Ahmed

1. **Final-road puzzle** (Museum key = key set **and** puzzle): design is Open. _Built:_ a neutral "seat each required key in the gate" puzzle (server-verified inventory, nothing spent). Replace when designed.
2. **Museum key set:** default = one key of every earlier first-visit location (shell, candle, music, token, letter, sunflower). Editable via `required_keys`.
3. **Café drinks** and **song-explanation card schema:** no drink list exists in any tab, so the drink interaction is **not built** (the Café's first interaction is the gramophone). Explanation cards read `08_UI_TEXT` by `explanation_text_id`. Produce-consumption hook for future drink recipes exists (`consumeProduce`).
4. **Seed acquisition, plot count, yields, wilt/recovery visuals:** Sheet crop rows drive timing; starter seeds are a temporary default (see §4); Marcelino-brought seeds not built.
5. **Church key on later days** (quiz vs. exterior): the first-visit key is the first candle. Later days follow `31_CHURCH_QUIZ.key_reward_type_id` (once per day). Candle-shaped exterior key not built.
6. **Candle persistence:** ordinary candles reset daily; a candle lit on a day with an approved `candle_occasion` row is preserved permanently.
7. **Marcelino schedule/learning formula:** schedules are config-driven (section 4) and default to _away_ (approved: not permanently present); the exact combined milestone formula is Open.
8. **Localized names:** _Church_ and _Marevi Cove_ are localized; _Vinyl Café, VARcade, Veoulla's Cottage, Sunberry Fields, The Everkeep_ show in English in all five languages until approved localizations exist.
9. **Where per-user location state lives:** to avoid a schema migration, each system keeps one JSON document in `37_CHARACTER_STATE.story_flags_json` on rows `<userId>|world_<system>` (candles, quiz, Café/Walkman, arcade unlocks, Cottage decor, Farm inventory, Museum flags, journey/rewards). **Please confirm or ask for dedicated tabs.** Song requests are written to `05_ENTRY_LOGS` (`song_request`, `pending_review`, Admin-visible; never auto-published).
10. **Legacy key-award endpoint:** retired in the closure pass; keys, spends and achievements are server-decided only.
