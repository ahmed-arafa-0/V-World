## 1. How to read this document

- **Cue ID**: the proposed `content_id` (paired with `content_type`) a `16_VOICEOVER` row group would use.
- **Speaker**: `15_DIALOGUE.speaker_id` — either `var` or narration-only (no speaker character shown).
- **Trigger**: which Phase 1 beat plays this cue.
- **Intent**: what the line needs to accomplish emotionally/narratively — not the final wording.
- **Locale requirements**: all five (`en`, `ar-EG`, `it`, `el`, `fr`) per the Living Bible §3A ("Approved voice-over content must exist in all five languages").
- **Approval status**: `draft` (engineering placeholder, this document) until Ahmed explicitly approves wording; then `approved-pending-recording`; then `recorded` once Ahmed supplies the audio file and it is registered in `10_ASSETS`.
- **Supplied file / timing**: blank until Ahmed supplies a real recording; draft `duration_ms`/`caption_start_ms`/`caption_end_ms` values used in test fixtures are placeholders for engineering (timing/pause-replay logic) only, never presented to a player as final.
